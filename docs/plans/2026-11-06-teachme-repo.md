# teachme — план

## 1. Понимание задачи

Опубликовать скил `learning-report` (создан в этой сессии) как публичный GitHub-репозиторий
`Vlad175cm/teachme`: MIT, README на английском и русском, установщик, CI-проверка скилов.
Цель — чтобы скил можно было поставить одной командой на другой машине и чтобы он не
деградировал при правках.

## 2. Критерии приёмки

- [ ] `gh repo view Vlad175cm/teachme` показывает public-репозиторий с описанием и темами
- [ ] В репозитории есть `skills/learning-report/SKILL.md`, `README.md`, `README.ru.md`, `LICENSE`, `install.sh`, `.github/workflows/validate.yml`
- [ ] `python3 scripts/validate_skills.py` завершается с кодом 0
- [ ] `install.sh` в чистом `HOME` копирует скил и добавляет блок в `AGENTS.md`
- [ ] Повторный запуск `install.sh` не создаёт второй блок (маркеры, идемпотентность)
- [ ] `install.sh --no-agents` не создаёт и не меняет `AGENTS.md`
- [ ] В локальном `~/.config/opencode/AGENTS.md` ровно один блок `teachme`
- [ ] CI-workflow проходит на первом push

## 3. Что НЕ входит

- Скил `task-understanding` и остальные локальные скилы
- Публикация в каталоги/маркетплейсы OpenCode
- Английская версия самого отчёта (перевод шаблона)
- Плагин, который добавляет правило без `AGENTS.md`
- Скрипт удаления (uninstall) — в README есть ручная инструкция

## 4. Допущения

| # | Допущение | Если не так — что меняется |
|---|-----------|----------------------------|
| 1 | ID скила остаётся `learning-report` | Меняются папка, `AGENTS.md` и локальная установка |
| 2 | Отчёт по умолчанию по-русски | Правится одна строка в `SKILL.md` и блоке `AGENTS.md` |
| 3 | Журнал в `$HOME/ai-devlog/` | Меняется раздел «Файл» в `SKILL.md` |

| 5 | Ветка `main`, аккаунт `Vlad175cm` | Меняются remote и ссылки в README |

## 5. Открытые вопросы

Нет: все развилки закрыты ответами пользователя (состав, имя, видимость, язык README,
лицензия, установщик, место локальной копии, ID скила).

## 6. Подход

**Вариант A — только скил + README.** Минимум, но установка руками в три шага, и никто не
проверяет, что `AGENTS.md` подключён. Отклонён: скил без триггера не работает «по умолчанию».

**Вариант B — скил + установщик + CI (выбран).** Установка одной командой, идемпотентность
через маркеры, валидатор ловит сломанный frontmatter до публикации. Цена — ~150 строк
bash/Python, которые надо поддерживать.

**Вариант C — плагин OpenCode, который добавляет правило в системный промпт.** Надёжнее
инструкций, но требует TypeScript, версионирования API плагинов и не переносится на другие
харнессы. Отложен как следующий шаг.

## 7. Файлы

## 8. Задачи

### Задача 1: Каркас репозитория

Цель: каталог `~/teachme` с лицензией и структурой.
Файлы: `LICENSE`, `.gitignore`, `skills/`, `scripts/`, `docs/plans/`

Шаги:
- [x] Создать дерево каталогов → `find` показывает нужные папки
- [x] Добавить MIT и `.gitignore` → файлы на месте

Проверка: `ls -R ~/teachme`
Готово, когда: структура совпадает с разделом 7.

### Задача 2: Скил в репозитории

Цель: `skills/learning-report/SKILL.md` идентичен рабочей версии и переносим.
Файлы: `skills/learning-report/SKILL.md`

Шаги:
- [x] Скопировать локальный скил → файл существует
- [x] Заменить `/home/vlad` на `$HOME` → `grep -r '/home/vlad' skills/` пуст

Проверка: `diff` с локальной версией
Готово, когда: различий нет, жёстких путей нет.

### Задача 3: Установщик

Цель: одна команда ставит скил и подключает триггер, повторный запуск безопасен.
Файлы: `install.sh`

Шаги:
- [x] Копирование скилов в `${XDG_CONFIG_HOME:-$HOME/.config}/opencode/skills`
- [x] Блок `AGENTS.md` с маркерами, бэкапом и заменой между маркерами
- [x] Флаги `--no-agents`, `--help`

Проверка: прогон в подставном `HOME`, дважды
Готово, когда: один блок после двух запусков, `--no-agents` не создаёт файл.

### Задача 4: Валидатор и CI

Цель: сломанный `SKILL.md` не проходит проверку.
Файлы: `scripts/validate_skills.py`, `.github/workflows/validate.yml`

Шаги:
- [x] Проверки: ID, `name` = имя папки, `description`, `Use when`, размер тела
- [x] `bash -n install.sh` в CI
- [x] Запуск на текущем скиле → `ok: 1 skill(s) validated`

Проверка: `python3 scripts/validate_skills.py`
Готово, когда: код 0 на валидном скиле и код 1 на испорченном.

### Задача 5: README на двух языках

Цель: человек снаружи понимает, зачем репо, и ставит его за минуту.
Файлы: `README.md`, `README.ru.md`

Шаги:
- [x] Описание, таблица 9 блоков, установка, настройка, проверка, удаление

Проверка: прочитать установку и выполнить её на чистой машине (симуляция — подставной `HOME`)
Готово, когда: шаги воспроизводятся без устных пояснений.

### Задача 6: Локальная установка

Цель: опубликованная версия совпадает с рабочей.

Цель: репозиторий доступен по `https://github.com/Vlad175cm/teachme`.
Файлы: `.git/`

Шаги:

## 9. Риски

| Риск | Вероятность | Чем ловим |
|------|-------------|-----------|
| `install.sh` затрёт чужой `AGENTS.md` | средняя | бэкап с таймстампом, изменение только между маркерами |
| Скил и блок в `AGENTS.md` разойдутся | средняя | раздел «Настройка» и чек-лист в скиле |
| Жёсткий путь `/home/vlad` утечёт в публичный репо | была | `grep` в задаче 2 и валидатор |
| CI не запустится на первом push | низкая | `gh run list` после публикации |
| Имя `teachme` занято | низкая | `gh repo create` вернёт ошибку до push |

## 10. Финальная проверка

```bash
cd ~/teachme
python3 scripts/validate_skills.py
bash -n install.sh

# установка в изолированный HOME
rm -rf /tmp/opencode/fakehome
HOME=/tmp/opencode/fakehome ./install.sh
HOME=/tmp/opencode/fakehome ./install.sh
grep -c '<!-- teachme:begin -->' /tmp/opencode/fakehome/.config/opencode/AGENTS.md
test -f /tmp/opencode/fakehome/.config/opencode/skills/learning-report/SKILL.md

# публикация
gh repo view Vlad175cm/teachme --json visibility,url,description
gh run list --limit 3
```

Ожидаемо: `ok: 1 skill(s) validated`, `1` блок после двух запусков, файл скила на месте,
`"visibility":"PUBLIC"`, запуск CI со статусом `completed/success`.

## 11. Если что-то пошло не так

- `AGENTS.md` испорчен → восстановить из `AGENTS.md.bak.<таймстамп>`, который создаёт установщик.
- Скил перестал находиться → проверить путь `~/.config/opencode/skills/learning-report/SKILL.md` и `description` в frontmatter.
- CI красный → запустить `python3 scripts/validate_skills.py` локально, текст ошибки указывает файл и поле.
- Репозиторий создан с неверным именем → `gh repo rename`, затем поправить ссылки в README.
- Публикация необратима только по факту индексации; при ошибке содержимое можно удалить и запушить заново.
